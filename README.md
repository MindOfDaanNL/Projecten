## 🚀 Getting Started

Want to explore any project?

1. **Browse** the [Projects](#-projects) section above
2. **Clone** this repository:
   ```bash
   git clone https://github.com/MindOfDaanNL/Projecten.git
   ```
3. **Navigate** to any project folder:
   ```bash
   cd Projecten/Projects/Commit-delete
   ```
4. **Follow** each project's individual `README.md` for setup instructions
